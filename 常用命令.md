# 常用命令

## 激活虚拟环境

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

## 安装依赖

```powershell
pip install -r requirements.txt
```

## 训练网络

默认读取 `config.json` 里的 `network_train` 配置：

```powershell
python network\train.py
```

临时快速测试训练流程：

```powershell
python network\train.py --epochs 2 --steps_per_epoch 10 --batch_size 16
```

## 评估 PM/PF 曲线

默认读取 `config.json` 里的 `network_evaluate` 配置：

```powershell
python network\evaluate.py
```

临时指定 checkpoint：

```powershell
python network\evaluate.py --ckpt checkpoint\checkpoints_N200_Lp30_M32_bs128_steps2000\last.pt
```

## 检测 + 信道估计对比

默认读取 `config.json` 里的 `CE_methods_compare` 配置，方法列表由 `CE_methods_compare.methods` 决定：

```powershell
python CE_methods\compare.py
```

## 对比真实/预测活跃用户索引

默认读取 `config.json` 里的 `network_compare_active_indices` 配置：

```powershell
python network\compare_active_indices.py
```

## 画训练 loss 曲线

这个脚本不读取 `config.json`，参数从命令行传入：

```powershell
python plot\plot_loss_curve.py --log checkpoint\checkpoints_N200_Lp30_M32_bs128_steps2000\train.log --out loss_curve.png
```

## 画 AMP 迭代 NMSE 曲线

默认读取 `config.json` 里的 `plot_plot_amp_nmse_vs_iter` 配置：

```powershell
python plot\plot_amp_nmse_vs_iter.py
```

## 常改配置位置

`config.json` 顶层名字对应脚本：

```text
network_train                    network\train.py
network_evaluate                 network\evaluate.py
CE_methods_compare               CE_methods\compare.py
network_compare_active_indices   network\compare_active_indices.py
plot_plot_amp_nmse_vs_iter       plot\plot_amp_nmse_vs_iter.py
```
